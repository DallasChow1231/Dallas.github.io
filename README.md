# POP MART Hong Kong — LABUBU & Blind Box Official Store Simulation

An interactive storefront simulation featuring POP NOW display trays, numbered slot selection, series character lineups (including **MEGA ROYAL MOLLY 100% 週年系列1** and **THE MONSTERS 一喵變貓系列**), template switching, a 20-second checkout timer, and an interactive unboxing & collection shelf experience.
